# Go тапсырма 9 — әр бөлімнің 10 есебі

Бұл папкада «9 тапсырма.docx» құжатының базалық, орта және зертханалық бөлімдерінен №10 тапсырмалар орындалған. Әр жоба жеке Go модулі ретінде іске қосылады. StudentApp бір модульдің ішінде `student`, `config`, `logger`, `utils` пакеттеріне бөлінген.

## Бірден іске қосу

**Компьютердегі дайын папкада:** `START.cmd` файлын екі рет басып ашыңыз. Мәзірден `1`, `2`, `3` немесе `4` таңдаңыз. Дайын Windows x64 бағдарламалары папкаға қосылған, олар үшін Go орнатудың қажеті жоқ.

**GitHub-тан жүктегенде:** `Code → Download ZIP` арқылы жүктеп, архивті толық шығарыңыз. Компьютерде Go 1.22 немесе жаңа нұсқасы болуы керек. Алдымен `BUILD.cmd`, содан кейін `START.cmd` ашыңыз. GitHub-та бастапқы код сақталады, `.exe` файлдары `.gitignore` арқылы алынып тасталған.

`03_studentapp/vendor` ішінде қажет кітапханалар бар. Сондықтан жоба коды жүктеліп, Go орнатылғаннан кейін жинау үшін интернет қажет емес.

## Базалық деңгейдің 10 есебі

`01_basic_time/main.go` файлында `time.Now()` компьютердің ағымдағы уақытын алады. `Format("2006-01-02 15:04:05 -07:00")` оны жыл, ай, күн, сағат, минут, секунд және UTC ығысуымен көрсетеді. Go-дағы `2006-01-02 15:04:05` — пішім үлгісі; экранға осы тұрақты күн емес, іске қосылған сәттегі уақыт шығады.

PowerShell немесе терминалда:

```powershell
cd 01_basic_time
go run .
```

## Орта деңгейдің 10 есебі

```text
02_internal_packages/
├── go.mod                       module internal10
├── main.go                      екі пакетті де шақырады
└── internal/
    ├── mathutils/math.go        Add және Multiply
    └── greetings/greetings.go  Hello
```

`main.go` ішіндегі импорт жолдары модуль атауынан басталады: `internal10/internal/mathutils` және `internal10/internal/greetings`. `internal` ішіндегі пакетті оның ата-аналық папкасының ішіндегі код қана импорттай алады. Осы жобада бұл шекара модуль түбіріне сәйкес келеді.

```powershell
cd 02_internal_packages
go run .
```

Күтілетін нәтиже:

```text
Сәлем, Диас!
10 + 5 = 15
10 * 5 = 50
Екі internal пакет бір модульден қолданылды.
```

## Зертханалық жұмыстың 10 есебі

```text
03_studentapp/
├── go.mod, go.sum       модуль және кітапхана тәуелділіктері
├── main.go              конфигурация, демонстрация және мәзір
├── config.json          бағдарлама параметрлері
├── student/             Student, қосу, көрсету және сүзу
├── logger/              уақыт белгісі бар INFO және ERROR
├── config/              JSON оқу және тексеру
├── utils/               ReadString және ReadInt
└── vendor/              сыртқы кітапханалардың жергілікті көшірмесі
```

```powershell
cd 03_studentapp
go run .
```

Қысқа демонстрация:

```powershell
go run . -demo
```

Өзге конфигурациямен іске қосу:

```powershell
go run . -config config.json
```

### Мәзірмен жұмыс

1. `1` — студент қосу. ID, тегі, аты, туған жылы, факультеті, курсы және тобы кезекпен енгізіледі.
2. `2` — барлық студенттерді көрсету.
3. `3` — факультет бойынша сүзу, мысалы `IT`. Үлкен және кіші әріп айырмашылығы ескерілмейді.
4. `4` — курс бойынша сүзу, мысалы `2`.
5. `0` — бағдарламаны жабу.

Қосып тексеруге болатын оқу мысалы: ID `4`, тегі `Омар`, аты `Дана`, туған жылы `2005`, факультеті `IT`, курсы `2`, тобы `CS-22`. Әдепкіде ID 1, 2, 3 болатын үш мысал студент бар. ID `1` мәнімен қайта қосу әрекеті қате хабарын шығарады және тізімді өзгертпейді. Бұлар — бағдарламаны көрсетуге арналған мысал деректер.

**Деректердің сақталуы:** студенттер тізімі бағдарлама ашық тұрған кезде жедел жадта сақталады. Жапқаннан кейін енгізілген жаңа студенттер жоғалады; келесі іске қосуда бастапқы мысалдар қайта жүктеледі. Тұрақты дерекқор немесе файлға сақтау тапсырма шартында талап етілмеген.

### Конфигурация

| Параметр | Қызметі |
|---|---|
| `app_name` | Іске қосылғанда көрсетілетін бағдарлама атауы |
| `default_faculty` | `-demo` режиміндегі факультет сүзгісі |
| `default_course` | `-demo` режиміндегі курс сүзгісі |
| `seed_students` | `true` болса, үш мысал студентті қосады |

### Толық Student Management System талаптарының орындалуы

| Талап | Іске асырылған жері |
|---|---|
| `studentapp` модулі | `go.mod` |
| Student құрылымының жеті өрісі | `student/student.go` |
| NewStudent және AddStudent | `student/student.go` |
| Үш студент қосу және тізімді шығару | `main.go`, `-demo` режимі |
| Факультет және курс бойынша сүзу | FilterByFaculty, FilterByCourse |
| INFO және ERROR уақыт белгісімен | `logger/logger.go` |
| ReadString және ReadInt | `utils/input.go` |
| Логиканы пакеттерге бөлу | student, config, logger, utils |
| Қайталанатын ID қатесін қайтару | AddStudent `error` қайтарады |
| Сыртқы түстер кітапханасы | `github.com/fatih/color` v1.18.0 |
| Толық біріктірілген мәзір | `main.go` |
| JSON конфигурациясын оқу | `config/config.go` |

`NewStudent` функциясына ID де беріледі, өйткені қайталанатын ID-ді тексеру керек. `AddStudent` функциясы құжаттың қате өңдеу талабына сай `error` қайтарады. `main` қатені ұстап, `logger.Error()` арқылы көрсетеді. INFO жасыл, ERROR қызыл түспен беріледі; файлға бағытталған шығыста түс кодтары автоматты өшеді.

## Тексеру

Ортақ папкада `CHECK.cmd` ашыңыз немесе әр модульдің ішінде орындаңыз:

```powershell
go test ./...
go vet ./...
go build .
```

`verification` папкасында орындалған тексерулер, нақты консоль нәтижелері және StudentApp демонстрациясы бар. Студентті қосу, қайталанатын ID, жарамсыз деректер, сүзгілер, JSON қателері, консольден енгізу және енгізу ағынының аяқталуы тексеріледі. Басқа модульден `internal` пакетін импорттау әрекетінің Go компиляторымен қабылданбауы да тексерілген.

## Ағайға көрсету реті

1. Әр бөлімнен №10 таңдалғанын және жоғарыдағы үш папканы көрсетіңіз.
2. Базалық жобаны іске қосып, `time.Now()` не істейтінін түсіндіріңіз.
3. Орта жобада екі `internal` пакетті және олардың импорттарын көрсетіңіз.
4. StudentApp-та `-demo` іске қосып, үш студентті, екі сүзгіні және ID қатесін көрсетіңіз.
5. Мәзірден өзіңіз бір студент қосыңыз, кейін `2`, `3`, `4` арқылы нәтижені тексеріңіз.
6. `config.json` пен пакеттердің міндетін түсіндіріңіз.
7. GitHub репозиторийінің сілтемесін жіберіңіз: https://github.com/tirrdias-afk/go-task9-variant10 . Репозиторий Public, сондықтан ағай сілтемемен аша алады.
